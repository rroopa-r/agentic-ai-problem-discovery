🤖 Agentic AI System for Automatic Problem Statement Discovery
 An intelligent AI-powered application that automates problem statement discovery by analyzing research topics and documents. It leverages Agentic AI, Natural Language Processing (NLP), and Large Language Models (LLMs) to identify key challenges and generate structured problem statements.

✨ Key Features
- 🔍 Automated Problem Discovery – Identifies potential research problems.
- 🧠 AI-Powered Analysis – Analyzes information using intelligent AI processing.
- 📄 PDF Processing – Extracts and analyzes text from PDF documents.
- 💡 Problem Identification – Discovers meaningful challenges from research information.
- 🌐 Interactive Interface – Provides a user-friendly web application.

🛠️ Technology Stack
Component| Technology
Frontend| React.js, TypeScript
Backend| Python, FastAPI
AI Frameworks| LangChain, LangGraph
Language Model| Ollama
Vector Database| ChromaDB

🚀 Getting Started

1. Clone the Repository
git clone https://github.com/YOUR-USERNAME/agentic-ai-problem-discovery.git
cd agentic-ai-problem-discovery

2. Backend Setup
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --reload

3. Frontend Setup
Open a new terminal:

cd frontend
npm install
npm run dev
